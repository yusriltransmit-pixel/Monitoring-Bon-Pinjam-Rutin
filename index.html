Pengaturan Spreadsheet

Konfigurasi koneksi ke Google Spreadsheet sebagai database

🔗 Koneksi Google Spreadsheet

Data bon pinjam akan disimpan dan disinkronisasi dari Google Spreadsheet yang Anda tentukan.

🚨 PENTING: Cara Deploy Script yang Benar agar Sync Berhasil
Saat melakukan New Deployment di Google Apps Script, perhatikan dua hal ini:
  1. Execute as: Pilih Me
  2. Who has access: Wajib pilih "Anyone" (Jika tidak "Anyone", Sync akan GAGAL atau nyangkut)
Ambil dari URL spreadsheet: docs.google.com/spreadsheets/d/[ID disini]/edit
Deploy Google Apps Script sebagai Web App agar data bisa ditulis dan dibaca.
📌 Cara Setup Google Apps Script:
  1. Buka Google Spreadsheet Anda
  2. Klik Extensions → Apps Script
  3. Paste kode Apps Script di bawah, klik Save
  4. Klik Deploy → New deployment → Web App
  5. Set "Execute as: Me", "Who has access: Anyone"
  6. Copy URL dan paste di field di atas

Helpdesk & Dokumentasi

Panduan lengkap dan informasi kontak bantuan operasional Warehouse Integrated Material System (WIMS).

Panduan Fitur Utama

📊 Dashboard Overview

Pusat informasi yang menampilkan ringkasan data, grafik tren MIV, komposisi status approval, dan metrik kepatuhan SLA harian.

📝 Data Bon Pinjam

Modul untuk mengelola data operasional bon pinjam. Pengguna dapat melakukan pencatatan bon pinjam baru, serta melakukan pengurutan (sorting) maupun pencarian data. Hanya Admin yang dapat menginput data.

⏰ Outstanding GI (Goods Issue)

Monitor khusus untuk bon pinjam yang telah melewati batas SLA tetapi belum dilakukan eksekusi Goods Issue oleh tim administrasi gudang.

✔️ Form Approval

Lacak status persetujuan secara real-time. Proses persetujuan dilakukan secara berjenjang oleh Officer, lalu Supervisor, hingga tingkat Section Head.

⚙️ Pengaturan Spreadsheet

Modul integrasi data eksternal ke lingkungan Google Workspace. (Menu ini membutuhkan otorisasi khusus dengan kata sandi).

Otorisasi Akun

  • Admin Warehouse: Akses input data dan manajemen keseluruhan operasional Bon Pinjam harian.
  • Officer: Kewenangan menyetujui Bon Pinjam pada tingkat pertama.
  • Supervisor: Kewenangan eskalasi dan persetujuan tingkat kedua (Supervisor dan Officer).
  • Section Head: Kewenangan tertinggi menyetujui semua level (SH, SPV, Officer).
